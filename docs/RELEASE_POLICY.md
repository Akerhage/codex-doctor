# Release Policy

No release is authorized by the documentation foundation alone.

Before distributing a Windows executable, verify dependency versions, build reproducibility, packaging configuration, application identity, security settings and a Windows smoke test. Record checksums and known limitations. Do not enable automatic updates or publish releases merely because a tag was pushed.

The repository owner must choose a license before a public software release. The empty LICENSE.md is intentionally not a license grant.

Recovery functionality requires additional version-specific safety validation. Release notes must distinguish implemented, tested and experimental capabilities.
